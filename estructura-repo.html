01Visión general

Monorepo Gradle con 6 módulos: un contrato compartido publicable (:sdui-core), un BFF Ktor (:server) y cuatro objetivos de cliente Compose Multiplatform (:shared + :androidApp + :desktopApp + iosApp). El servidor describe la UI como un árbol JSON tipado; el cliente lo renderiza. El contrato único en commonMain da type-safety end-to-end sin codegen.

05API HTTP · :server

EndpointRespuesta
GET /health200 "OK"
GET /screen/{id}200 SduiEnvelope · 404 problem+json

Plugins activos: ContentNegotiation (reusa DefaultSduiJson), StatusPages → ProblemDetail, CallId (X-Request-Id), Compression (gzip), DefaultHeaders, CORS deny-by-default (KUISD_CORS_HOSTS). Lee el header de capability X-Kuisd-Version. Pantallas resueltas por ScreenRegistry.

07Publicación & calidad

Las librerías sdui-* se publican a Maven con una convención que se auto-aplica a cualquier módulo con ese prefijo (grupo dev.kuisd): ./gradlew publishToMavenLocal o a un repo remoto vía -Pkuisd.publish.url/user/password. Gates de calidad: detekt + ktlint en todos los módulos; tests con kotlin.test + testApplication (Ktor).
